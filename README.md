# Sorting-Algorithms-Comparison
Compares heap sort, insertion sort, merge sort, quick sort, and selection sort runtimes with custom input.

## Input Format (`input.txt`)

The program reads data from a text file via standard input. It works with any custom input as long as it follows this format:

    ```text
    NumElements
    Element 1
    Element 2
    ...
    Element N


## How to Run
1. Compile all Java files:
    ```bash
   javac *.java

2. Run the program using the input file:
    ```bash
   java SortingComparison < input.txt
